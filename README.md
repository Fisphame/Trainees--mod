# Trainees — 引擎部分

本仓库是 **Trainees**（Minecraft 1.20.1 / Forge）的**引擎与框架部分**，有意**不包含**具体内容
（物质表、反应表、配方数值），它们属于私有内容包。

## 这是什么

- **魔法线**：精炼精华（Refined Essence, RE）作为货币，提取/聚合/富集三台机器、玩家魔力、
  加点系统（26 条属性）、精炼精华网（多方块端口 + 总线）。
- **化学线**：一个**数据驱动**的化学模拟引擎——物质、反应、相变、气网、容器腐蚀、产品规格判定。
  引擎本身不含任何具体物质或反应；内容由数据包提供。

## 构建

```bash
./gradlew build      # 产物在 build/libs/
./gradlew runClient  # 开发客户端（需要 Java 17）
```

> **关于测试**：本仓库**不包含单元测试**（测试源码里含具体数值，属于私有内容）。
> 引擎的测试在私有仓库里运行；这里保证"能编译、能启动、能跑演示内容"。

## 内容从哪来

引擎在服务器启动时读取数据包里的 JSON：

```
data/<namespace>/chemistry/ions/*.json        物质
data/<namespace>/chemistry/reactions/*.json   反应
data/<namespace>/chemistry/hazard_kinds.json  危险杂质映射（可选）
```

字段、单位、默认值与校验规则的完整说明见 [`docs/CHEMISTRY_DATA_SCHEMA.md`](docs/CHEMISTRY_DATA_SCHEMA.md)。

**设计原则**：

1. **机制在代码、内容在数据**——引擎不应出现任何具体物质名或数值；
2. **无法用数字表达的参数**（如动态优先级函数）由引擎注册为**命名函数**，数据只引用 id；
   引用不存在的函数 **= 硬错误**（不静默降级）；
3. 内容缺失时引擎**仍能启动**（降级运行），不会崩。
